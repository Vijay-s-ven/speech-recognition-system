# Speech Recognition System

## CODTECH Internship Task - 2

### Project Title
Speech-to-Text Recognition System Using Python

## Description
This project is a basic Speech Recognition System developed using Python and the SpeechRecognition library. The system converts speech from an audio file into text using Google's pre-trained speech recognition model.

The application is capable of transcribing short audio clips accurately and demonstrates the implementation of speech-to-text technology.

---

## Features
- Converts speech audio into text
- Supports WAV audio files
- Uses Google Speech Recognition API
- Beginner-friendly implementation
- Simple and lightweight project

---

## Technologies Used
- Python
- SpeechRecognition Library
- Google Speech Recognition API
